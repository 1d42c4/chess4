# Chess

If you are a real one who really wants to learn, this repo is for you!

A HUGE collection of free chess tutorials-contains 2,027 files, including 1,547 PDFs. 

If you are new to github click the green code button and download the zip file to get all of the lessons at once ! 

## What’s here

Different formats, too: text, PDF, and HTML!

- `/html` contains ZIP collections of HTML lessons. One archive alone contains 1,000 pages, each a separate chess lesson. Extract the files to read them offline in a browser or publish them on a website.
- `/pdf` contains ZIP collections of PDF tutorials, organized for studying and practicing.
- [`/group1`](group1) contains the additional course library, with 1,449 PDFs plus PGN practice files, indexes, study trackers, and starting guides. Its original folder organization is preserved.

Download a ZIP, extract it, and start learning. Check the included README or starting guide for instructions.

The large [`Complete Chess PDF Courses.zip`](group1/aipdf/older%20style/Complete%20Chess%20PDF%20Courses.zip) archive uses Git LFS. Download it from its file page using **Download raw file**, or clone this repository with Git LFS installed. GitHub's generated repository ZIP may contain only a pointer for this one archive; the individual PDFs in `group1` are stored directly in Git.

Copy the material, put it on your own sites, or build a course with it—including a paid course where the included license permits it. Follow each collection’s license and preserve any required credits, notices, and source files.

## About “AI slop”

I have no respect for chess youtube clowns who do content farming, copying smaller creators without credit, or pushing uploads just to keep the content machine running.

Calling everything made with AI “slop” while recycling other people’s ideas is not much of an argument. HUMAN SLOP is still slop.

AI keeps getting better, the human brain does not. Nevertheless, if you find an incorrect move, a bad explanation, or something genuinely misleading, point it out. That is useful criticism.

Just shouting “AI slop” contributes nothing. Show the error. Explain the correction. Make something better.

The point of this repository is to help people learn chess.

## Corrections and contributions

I do not accept outside content submissions because authorship and permission to redistribute are not always easy to verify.

Corrections are welcome. Include the archive, filename, page or lesson, and the move or explanation you believe is wrong.

Checks and verification notes are included where available. Mistakes can still happen, and I want them corrected.
